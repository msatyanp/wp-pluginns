# Newar Heritage Theme

Newar Heritage is a custom WordPress child theme built for a Newari heritage community website. It is designed to feel warm, cultural, and editorial while remaining lightweight and easy to customize.

## What It Provides
- A heritage-inspired style system with custom colors, typography, and decorative patterns
- Homepage and page templates tailored for community storytelling and content presentation
- Responsive layouts for modern WordPress sites
- Styling support for the Newar Members plugin’s member cards and directory output

## Design Notes
- Palette: Terracotta, maroon, gold, wood, cream, and ink
- Headings: Devanagari-friendly serif fonts
- Body text: clean sans-serif styling for readability
- Decorative motifs: carved wood, pagoda-inspired shapes, and lattice-style patterns

## Key Files
- style.css — theme styles and design tokens
- functions.php — theme setup, scripts, and support declarations
- header.php and footer.php — site header and footer structure
- front-page.php — custom homepage layout
- page.php and index.php — standard page and archive fallback templates

## Activation
1. Install and activate the parent theme Twenty Twenty-Four.
2. Place the Newar Heritage theme folder into wp-content/themes/.
3. Go to Appearance → Themes and activate Newar Heritage.
4. If you want to use the custom homepage template, set a static front page under Settings → Reading.

## Integration with the Plugin
The theme styles the [newar_members] shortcode output from the Newar Members plugin, including the member grid and member cards.
